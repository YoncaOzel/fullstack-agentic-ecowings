# EcoWings Frontend

This folder contains the EcoWings React application.

For full project documentation, see the root README:

- `../README.md`

## Setup

```bash
cd ecowings
npm install
```

## Environment

Copy `.env.example` to `.env`:

```env
VITE_API_URL=https://your-backend.com
VITE_API_BASE_URL=http://localhost:5000
```

## Run

```bash
npm run dev
```

Default URL: `http://localhost:3000`

## Build

```bash
npm run build
npm run preview
```
